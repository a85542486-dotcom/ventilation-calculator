# 산업환기 계산기 — m 기본 설정판

- 길이 단위: m(기본), cm, mm. dm(데시미터) 선택지는 삭제했습니다.
- 초기화 버튼을 누르면 길이 단위가 m로 돌아갑니다.
- 부스식 Q(m³/min) = 60 × 제어속도(m/s) × 가로(m) × 높이(m).
- 단위가 m일 때 가로 7, 높이 5, 제어속도 5 -> 10,500 m³/min.
- 105 m³/min을 원하면 동일한 제어속도에서 가로 0.7m, 높이 0.5m를 입력하세요.
